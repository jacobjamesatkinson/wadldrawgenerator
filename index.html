Credentials & tournament

“Round to post” is the draw you are building. Standings and history use completed rounds before that (for round 1, there is no prior data).

Action 1 — Load tournament from Tabbycat

One click loads everything needed for pairing: all teams, standings (through completed rounds before “Round to post”; pairing still uses team points from the API), debate history for rematches / sides, and all Tabbycat rooms (GET …/venues) so each debate can be matched to a physical room when you generate and post. The log lists each request underneath this action.

Team roster

After Action 1 you see name and total speaks from …/teams/standings/rounds (through the round before “Round to post”). Venue and timeslot stay blank until Action 2. Click a column header to sort (numbers vs text); click again to reverse.

Run Action 1 to load teams.

Action 2 — Apply scheduling CSV

Paste CSV below or choose a file (pasted text wins if both are set). Primary format: team_name, score (ignored — power pairing uses API only), venue, timeslot. The venue column is your site / division label for grouping (teams only meet others with the same venue + timeslot). For posting, it is matched to Tabbycat room name or display_name from Action 1, ignoring case and extra spaces. One site label can map to several Tabbycat rooms (e.g. names starting with Hale or Hale-); matching rooms are handed out in Tabbycat priority order (then id) to each debate in the site, across all timeslots. Room names no longer need to encode a clock time — the debate's scheduled_at carries the date + timeslot on POST (set the date per venue in the draw table). Names must match Tabbycat code name or short name (same as the roster column), then reference / long name. Alternative: team_id instead of team_name. The Tabbycat BYE placeholder may appear as team_name,BYE (or its team_id) with empty venue and timeslot — it is not assigned to a pool. Do not use points / wins columns (those would override the API rule). Same-school detection uses the name before the number (e.g. Hale 1 and Hale 2 → Hale). If no room matches, the debate still generates but posts without a venue until you align CSV labels with Tabbycat room names. You can also list extra scheduling-exempt team IDs below (flex/bye placeholders that never need a venue×timeslot row).

        Action 3 — Generate draw

        Runs only in your browser (no API). Needs Action 1 + Action 2 complete with no missing teams. The draw table shows total speaks under each side, bracket headers (speaks tie bands / pull-ups), and clash pills (short text; hover for detail). The table includes Room (Tabbycat) from the loaded venues list. Bracketing uses total speaks only (wins ignored). Row tint: rematch > power/floater > same institution. After generating, use the dropdowns to change affirmative/negative (or ⇄ to swap); posted rows are locked.
